# Research code access / 研究代码申请

## Application

The ENUSP implementation is available for non-commercial research. Applicants
must handwrite and sign the undertaking in [RESEARCH_UNDERTAKING.md](RESEARCH_UNDERTAKING.md)
and email a legible scan or photograph to **meidachuan@tju.edu.cn**.

Include your name, institution or research affiliation, contact email, and a
brief description of the intended research. A Chinese or English undertaking is
accepted. A typed undertaking with only a pasted signature does not satisfy the
handwritten requirement.

**Within 15 calendar days after receipt of a complete handwritten undertaking,
the ENUSP code package will be sent to the applicant's email address.** The
15-day period starts when all required application information is received.
If information is missing, please supply it in the same email thread.

Suggested subject: `ENUSP Code Request — Name — Institution`.

## Conditions

- Use the supplied code only for non-commercial scientific research, including
  method study, reproducibility work, and academic evaluation.
- Do not use it in commercial products, paid services, or commercial deployment
  without separate written permission from the authors.
- Do not publish, redistribute, or forward the supplied source package, or a
  modified version containing it, to others without written permission. Other
  researchers should submit their own applications.
- Cite the ENUSP paper in resulting publications and retain authorship and
  attribution notices in the code. Clearly identify modifications in your work.
- Obtain datasets separately and comply with their providers' access and use
  conditions. Code access does not grant rights to third-party data or software.

These conditions do not prevent publishing research findings, evaluation
results, or academic discussion of the method. Requests outside this research
scope should be sent to the contact email for separate consideration.

## 中文申请说明

申请人须亲笔抄写并签署[研究用途承诺书](RESEARCH_UNDERTAKING.md)，将清晰扫描件或照片
发送至 **meidachuan@tju.edu.cn**，并提供姓名、单位或研究归属、联系邮箱和研究用途。
中文或英文承诺书任选其一。仅打印正文后粘贴签名不满足手写要求。

**收到完整手写承诺书后 15 个自然日内，将通过申请邮箱发送 ENUSP 代码项目。**
如材料缺失，请在原邮件中补齐；期限自材料齐备之日起计算。

邮件主题建议：`ENUSP代码申请—姓名—单位`。

代码仅限非商业科研使用。未经作者书面许可，不得用于商业产品、收费服务或商业部署，
不得公开、转发或再分发代码及包含该代码的修改版本。其他研究者应独立申请。
相关成果须引用 ENUSP 论文，保留作者归属信息，并说明所作修改。
数据集需单独获取并遵守原提供方的使用条件。
上述条件不限制正常发表研究结论、评测结果或方法讨论。
